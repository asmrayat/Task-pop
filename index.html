A quick list that shows up on its own.

No app to remember to open. TaskPop lives on your computer and appears the moment you start using it.

  • Pops up when you start your computer

Your tasks stay on your computer.

There’s no account to create and nothing is sent to a server. TaskPop saves every change on your computer, keeps a backup of the previous save, and lets you export your list to a file whenever you want.

  • No sign-up
  • No cloud
  • No tracking
  • Automatic backup
  • Export and import

Installed in about a minute.

  1. Download the installer

    Choose macOS or Windows below. The Mac file is one installer for Apple Silicon and Intel.

  2. Open the installer

    On a Mac, open the disk image and double-click Install TaskPop. On Windows, run the .exe and follow the steps.

  3. Allow it once on a Mac

    macOS blocks apps that aren’t from the App Store. Open System Settings → Privacy & Security, scroll down, click Open Anyway, then confirm.

  4. Start using it

    On a Mac, TaskPop appears in the menu bar. Press ⌃⌥T any time. On Windows it opens after setup finishes.

Questions

Why does macOS ask me to confirm the installer?

TaskPop isn’t distributed through the Mac App Store, so macOS treats it as an app from an unidentified developer. After you open the installer, go to System Settings → Privacy & Security, scroll down and click Open Anyway. Confirm the prompt. You only need to do this once.

Which computers does TaskPop work on?

Any Mac running macOS 13 Ventura or later — Apple Silicon and Intel use the same download — and PCs running Windows 10 or 11.

Where are my tasks saved?

Only on the computer you use. Every change is saved straight away with a backup of the previous version. You can export your tasks to a file from Settings.

Can I change the keyboard shortcut?

Yes. Open Settings from the menu bar icon, click the shortcut and press the keys you want to use.

Will it pop up every time I unlock my computer?

By default it appears when you start your computer and when you unlock the screen. You can turn either of these off in Settings.

Does it sync between computers?

No, your tasks stay on the computer you use. To move them to another computer, export them from Settings and import the file there.

Does it work on Windows?

Yes. Download the Windows installer, run the .exe, and follow the setup steps. If Windows shows a SmartScreen warning, choose More info and then Run anyway.

How do I update TaskPop?

TaskPop checks for a new version on its own, shortly after you open it and again every few hours. You’ll see a notification, an Update button at the top of the task panel, and an Update item in the menu bar or tray menu. On a Mac you enter your password once, then TaskPop installs and reopens. On Windows it closes, updates, and reopens with no extra prompts. Your tasks and settings stay. If your copy is older and has no updater, download the newest installer from this page once.

How do I uninstall it?

Click the TaskPop icon in the menu bar, turn off Open at Login and choose Quit. Then drag TaskPop from Applications to the Trash. To remove your tasks too, delete the TaskPop folder in ~/Library/Application Support.

How to install TaskPop on macOS

macOS will show a security warning because TaskPop is not from the App Store. Follow these steps once.

  1. Open the downloaded file Find the TaskPop disk image in Downloads and double-click it. Then double-click Install TaskPop.
  2. If you see “Apple cannot check it for malicious software” Click OK or Done on that warning. This is normal for apps that are not in the Mac App Store.
  3. Open Privacy & Security Go to the Apple menu → System Settings → Privacy & Security. Scroll to the Security section at the bottom.
  4. Click Open Anyway You should see a note that TaskPop was blocked. Click Open Anyway, enter your password or use Touch ID, then click Open.
  5. Finish the installer Follow the remaining installer screens. TaskPop opens in the menu bar when it is done. Press ⌃⌥T any time.
